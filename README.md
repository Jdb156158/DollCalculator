# 玩偶计算器

一个中文网页小游戏：按数字键逐位回答加减法，玩偶会伸手抓住数字并送到答案格。答对后它会庆祝，纸屑、背景和合成音效会随着进度变得更热闹。答错可以直接重试，完成十题后显示本局结果。

在线体验：[玩偶计算器](https://jdb156158.github.io/DollCalculator/)

## 本地运行

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。手机可以点屏幕键盘，电脑也可以使用数字键和退格键。音效可开关；点击快乐值旁的设置按钮，可以选择 4–5 岁、6–7 岁或 8 岁以上的题目难度，也可以切换棉棉兔、布丁熊、泡泡猫。年龄和玩偶选择会保存在本机；玩偶立即切换，切换年龄会按新难度重新开始十题。

玩法和页面氛围参考了 [dopa-drill](https://github.com/grmchn/dopa-drill)。背景 WebGL 渲染改编自其 `app/js/bg.js`，原版权声明与许可证见 [third_party/dopa-drill/LICENSE](third_party/dopa-drill/LICENSE)。背景中的原角色剪影已替换为星星；三只玩偶及星星伙伴是本项目重新绘制的角色，没有使用参考项目的角色素材。本项目是非官方作品。
